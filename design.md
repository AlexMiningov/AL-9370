# Design — Lelikow Mining

## Aesthetic
Dark tech / crypto terminal. Inspired by cultholdings.co — monospace labels, status indicators, minimal UI, raw industrial feel. Adapted for mining expert personal brand.

## Colors
- Background: `#0a0a0a` (near black)
- Surface: `#111111`
- Border: `#1e1e1e`
- Accent: `#00ff88` (electric green — mining/crypto energy)
- Accent dim: `#00ff8820`
- Text primary: `#f0f0f0`
- Text secondary: `#666666`
- Text muted: `#333333`

## Typography
- Display/Labels: **IBM Plex Mono** — monospace, techno, terminal feel (Google Fonts)
- Headings: **Unbounded** — wide, bold, aggressive (Google Fonts)
- Body: **IBM Plex Mono** — consistent mono feel
- Import: Google Fonts

## Layout
- Full-width sections with subtle dividers
- Status bar aesthetic — KEY: VALUE label rows
- Asymmetric hero with oversized text
- Minimal padding, controlled density
- Thin 1px borders on sections/cards
- NO rounded corners (sharp edges only)
- NO shadows (flat)

## Motion
- Staggered fade-in on page load
- Blinking cursor effect on hero
- Counter animation on stats
- Smooth scroll

## Sections
1. Hero — name, title, status labels, CTA buttons
2. Trust — "Почему мне доверяют" — 8 years, capability list
3. Services — 4 service cards
4. Prices — table/list
5. Contact — form + telegram link
